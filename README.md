# Mizagonia

Мод для Minecraft 1.21.1 на HollowEngine. В игре десять подпутей. Первый из них — **Легион** — полностью готов: паровая промышленность, коксовая печь, горн, литейный двор, паровой молот и прокатный стан, котёл с трубами, цитадель, машины, большой поезд-база, оружие, доспехи и цепочка квестов.

## Установка

1. Установите Minecraft 1.21.1 с NeoForge, удобнее всего через лаунчер с профилями (Prism, Modrinth App, CurseForge, AstralRinth).
2. Положите в папку `mods` профиля два файла: `Mizagonia.jar` и `HollowEngine-1.21.1-2.4.0.jar` (обе ссылки выше).
3. Запустите игру и создайте новый мир или откройте копию старого.
4. Чтобы обновиться, скачайте `Mizagonia.jar` заново по ссылке выше и замените старый файл в `mods`.

## Игра вместе

- У всех игроков должны быть **одинаковые** версии `Mizagonia.jar` и HollowEngine.
- Если играете на отдельном сервере, те же файлы кладутся в его папку `mods`.
- Не кладите рядом с JAR папку проекта Mizagonia в `hollowengine/scripts`, иначе будут дубли.

## Если что-то не работает

Напишите HoMaX и приложите файл `logs/latest.log` из папки профиля и номер сборки `e1e63d59`.
